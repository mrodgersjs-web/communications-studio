# Internal Communication — RIG Communication Protocol V10

## Structure

```
Line 1: [WHAT YOU NEED FROM THEM — action, decision, or awareness]
Line 2: [CONTEXT — only what they need to act]
Line 3: [DEADLINE if applicable]
Line 4: [WHERE TO FIND MORE DETAIL if they want it]
```

## Deviation Ladder

| Lv | Example |
|----|---------|
| **-5** | Subject line IS the message. Body empty. |
| **-3** | One sentence. Action + deadline. |
| **0** | 3 paragraphs of context before the ask. |
| **+3** | Action first, context second, link to detail. |
| **+5** | So clear the recipient acts without reading twice. |

## Targets
- E1: -3 to +1 | E2: -3 to +1 | E3-E5: +1 to +3
- **Min to send:** E3 ≥ +1

## Principle
Maximum clarity, minimum words. Respect everyone's time. The median (0) is the 3-paragraph email that buries the ask. RIG internal communication puts the ask first.
